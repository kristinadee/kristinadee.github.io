# kristinadee.github.io

Engineering portfolio of Kristina Isabella E. Dee — mechanical engineering, Columbia
University, May 2027.

**Live site: [kristinadee.github.io](https://kristinadee.github.io)**

Patient-specific finite element modeling of soft tissue for women's health, reinforcement
learning for building controls, and hands-on mechanical design and manufacturing.

## Selected work

| Project | What it is |
|---|---|
| [Multi-patient uterine mechanics](https://kristinadee.github.io/projects/uterine-fea.html) | Scaled a verified single-patient modeling framework to a five-patient cohort. 3.6 ± 2.2 mm mean nodal agreement across 580,749 nodes. |
| [RL for building heating control](https://kristinadee.github.io/projects/rl-hvac.html) | Soft Actor-Critic agents in FMU co-simulation, stabilized with TD3 techniques. Code in `code/rl-hvac/`. |
| [Bi-pedal jumping robot](https://kristinadee.github.io/projects/biped-robot.html) | Concept sketches through two full CAD iterations, with the redesign that made it able to jump. |
| [Cast and injection-molded model car](https://kristinadee.github.io/projects/materials-car.html) | Silicone casting from printed molds, injection molding from CNC-machined aluminum tooling. |

Thirteen projects in total — see [all projects](https://kristinadee.github.io/projects.html).

## Repository layout

```
index.html          Home
projects.html       All projects, tag-filtered
about.html          Bio, skills, contact
style.css           Design tokens at the top control the whole site
projects/           One page per project
assets/<slug>/      Figures, one folder per project
assets/docs/        Reports and résumé
code/rl-hvac/       Soft Actor-Critic training scripts
```

Static HTML and CSS, no build step, served by GitHub Pages. Fonts from Google Fonts; everything
else is local.
